🚀 QUICK START
================================================================================

1. Start the application:
   
   ./scripts/start_custom.sh

   OR with Ollama + GPU:
   
   docker compose -f docker-compose.custom.yml --profile ollama up --build

2. Pull a vision model (in another terminal):
   
   docker exec ollama ollama pull llama3.2-vision:11b

3. Access the web UI:
   
   https://localhost:8090
   (Accept SSL warning: click "Advanced" → "Proceed to localhost")

📋 COMMON COMMANDS

./scripts/start_custom.sh

./scripts/start_custom.sh --nim

# View live logs
docker compose -f docker-compose.custom.yml logs -f live-vlm-webui

# Shell into container
docker compose -f docker-compose.custom.yml exec live-vlm-webui bash

# Stop services
docker compose -f docker-compose.custom.yml down

# Rebuild without starting
docker compose -f docker-compose.custom.yml build

# Clean everything and rebuild
docker system prune -a
./scripts/start_custom.sh

================================================================================
🆘 TROUBLESHOOTING
================================================================================

Q: "Build fails with dependency error"
A: Clear Docker cache: docker system prune -a && ./scripts/start_custom.sh

Q: "Port 8090 is already in use"
A: Stop other services: docker ps | grep 8090 → docker stop <container>

Q: "Webcam not working"
A: Using HTTPS? ✓ Accept SSL warning? ✓ Browser permissions? ✓

Q: "GPU not detected"
A: Run with: docker run --gpus all live-vlm-webui:custom

Q: "Changed code but changes don't show up"
A: Rebuild the image: ./scripts/start_custom.sh

For more help, see CUSTOM_BUILD_GUIDE.md
